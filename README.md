# Pikhta Servers

Сайт услуги «Discord‑сервер под ключ»: каналы, роли, права, боты, защита и оформление.

🌲 **Сайт:** https://pikhta.github.io/discord/
💬 **Заказать:** [Telegram @nepikhta](https://t.me/nepikhta)

## Что на сайте

- интерактивный 3D‑бот на главном экране (three.js);
- спецпредложение с таймером до конца дня;
- что входит в работу и как проходит заказ;
- живые примеры структуры серверов;
- прайс, форма заявки в Telegram и FAQ.

## Запуск

Сборка не нужна: достаточно открыть `index.html` в браузере (для 3D и шрифтов нужен интернет).
